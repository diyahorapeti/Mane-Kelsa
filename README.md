Mane Kelsa is an Android application developed to help users easily find and contact nearby workers such as plumbers, electricians, carpenters, painters, and cleaners.
The app provides worker details, profile images, phone call support, and multilingual support in Kannada and English
 Features

- Worker listing
- Search functionality
- Direct call support
- Worker profile images
- Kannada and English language support
- Simple and user-friendly UI
- Firebase integration
- Location support

Technologies Used

- Kotlin
- Android Studio
- Firebase
- RecyclerView
- Material Design
- XML Layouts

1. Clone the repository
git clone https://github.com/thanushreemk164-code/Mane-Kelsa.git

2. Open the project in Android Studio

3. Sync Gradle files

4. Connect an Android device or start an emulator

5. Click Run
